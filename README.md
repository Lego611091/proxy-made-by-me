# Simple Libcurl Browser

This is a tiny text-based browser that fetches HTML using libcurl (via pycurl).
It can optionally route requests through a proxy such as eproxy.

## Features
- Fetches HTML from any URL
- Prints raw HTML in the terminal
- Optional proxy routing through config.json
- Beginner-friendly project structure

## Requirements
- Python 3
- pycurl (`pip install pycurl`)
